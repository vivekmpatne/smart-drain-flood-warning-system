# Intelligent Water Clogging and Flood Prevention

## Problem
Bengaluru faces flooding within minutes of rain.
No real-time drain monitoring exists.

## Solution
IoT system that monitors drain water level,
calculates rate of rise, and predicts flood risk
before it becomes critical.

## Tech Stack
- ESP32 (sensor + actuator nodes)
- MQTT (EMQX broker)
- Node-RED (processing + logic)
- FlowFuse Dashboard 2.0
- OpenWeatherMap API

## Features
- Real-time water level monitoring
- EMA smoothing + rate-of-rise calculation
- 4 alert states: Normal/Watch/Alert/Critical
- Auto-escalation after 60s unacknowledged
- Email alerts to control room
- Citizen reporting dashboard
- LED + buzzer on-site indicators
